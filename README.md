# The Arches Server

The Arches Server is a club-focused Chess dashboard and member portal built for The Arches Server community. It brings together live club data, member status, calendar events, ratings, and rewards in a polished single-page app.

Live demo:
https://liamlesser.github.io/TheArchesServer/

## Overview

This project provides a custom experience for Arches members, with:
- Member sign-in via Chess.com username verification
- Club overview and live member activity
- Leaderboards with rating tracking
- Club calendar and upcoming events
- Member roster and player details
- Arches Points and reward system
- Personalized stats and recent game history

## Features

- Public Chess.com integration for live club and player data
- Responsive dashboard layout
- Member authentication using Chess.com profile verification
- Personalized profile stats for signed-in users
- Club leaderboard rankings across Rapid, Blitz, Bullet, and Daily
- Calendar view for club matches and public tournaments
- Arches Points tracking and shop/reward flow
- Local browser settings and theme customization
- Built as a static site deployable on GitHub Pages

## Tech Stack

- React
- Vite
- JavaScript / JSX
- CSS
- Chess.com public API
